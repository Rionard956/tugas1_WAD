Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa untuk menyusun struktur halaman web, seperti judul, paragraf, gambar, dan tautan.

Apa itu Tailwind CSS?

Tailwind CSS adalah framework CSS yang gayanya ditulis langsung sebagai class di HTML, misalnya flex atau text-center, tanpa menulis file CSS sendiri.
