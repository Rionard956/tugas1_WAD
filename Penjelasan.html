Penjelasan HTML

HTML berfungsi sebagai kerangka halaman web. Isi halaman dibungkus dengan tag, misalnya <h1>Judul</h1> untuk judul dan <p>Teks</p> untuk paragraf.

Penjelasan Tailwind CSS

Tailwind mengatur tampilan lewat class di dalam tag. Contohnya <header class="flex justify-between"> membuat isi header berjajar ke samping dengan jarak di kiri dan kanan. Setiap class mewakili satu properti CSS.
